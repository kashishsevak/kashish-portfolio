# Kashish Sevak --- Portfolio

A modern, responsive **MERN Stack Developer Portfolio** built with React
and Vite.

## Tech Stack

-   React 18
-   Vite
-   CSS
-   Lenis (smooth scrolling)
-   JavaScript

## Features

-   Responsive modern UI
-   Hero, About, Skills, Projects and Contact sections
-   Dark/Light blue theme
-   Custom cursor
-   Smooth scrolling and scroll animations
-   Scroll progress bar
-   Back-to-top button
-   Responsive navigation
-   Project GitHub/Live Demo links
-   Replaceable profile photo

## Projects

-   **GlowEssence** --- Group full-stack project with GitHub and Live
    Demo
-   **E-Commerce** --- GitHub project
-   **Blog** --- GitHub project

## Installation

``` bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://localhost:5173`.

## Production Build

``` bash
npm run build
npm run preview
```

## Profile Photo

Place your photo here:

`public/images/profile.jpg`

A square image (around 800×800px or higher) is recommended.

## Customize

-   Skills: `src/data/skills.js`
-   Projects: `src/data/projects.js`
-   Hero: `src/components/Hero.jsx`
-   About: `src/components/About.jsx`
-   Contact details: `src/components/Contact.jsx`

## Deployment

The project can be deployed on **Vercel, Netlify, or any static hosting
service** after running:

``` bash
npm run build
```
